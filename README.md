# 要素与介绍核对

先从合同提取要素表，再拿要素表和公司介绍、经理介绍底稿去对一页通。对不上的介绍，以及最下面的风险揭示，写成 Word 修订，可以下载。

日常使用这个网站：https://zylugarry-lab.github.io/intro-baseline-review/

页面只在浏览器里处理文件，不会把材料上传到服务器。要素表、公司介绍和经理简介的修改保存在这台浏览器里。

## 三步

1. **合同要素**
   - 上传一份或多份集合计划合同，doc 或 docx 都可以。每份合同单独生成要素表，下载的 Excel 里各占一个工作表。只下载要素、不去对一页通也可以。
   - 产品风险等级按通用版或建行版生成。销售机构如果另给了评级，在下拉里选上，这句话会补进风险表述。

2. **内容底稿**
   - `assets/manager-introductions.xlsx`：姓名、简介、从业日期、投资起始日期。
   - `assets/company-introduction-general.docx`：通用版公司介绍。
   - `assets/company-introduction-ccb.docx`：建行版公司介绍。
   - 从业年限、投资年限用制作日期减去对应起始日期，按 365 天下取整。不满一年保留一位小数。
   - 公司介绍和经理简介在页面上直接改。

3. **对照一页通**
   - 上传一页通，doc 或 docx 都可以。公司介绍或经理介绍和底稿不一致时，写入 Word 修订。投资经理以合同名单为准，多的删除，少的用底稿简介补上。开头的产品名称改成和合同一致，产品要素表按合同要素逐项修改，底部风险揭示跟着要素里的风险等级改。一页通如果写了锁定期天数，会改成和开放期里的天数一致。修订稿下载为 docx。
   - 一页通里的风险等级和最下面的风险揭示，改成和要素表里的产品风险等级一致，包括销售机构另给的评级。
   - 没被改到的旧修订保持原样。

## 网站

打开 https://zylugarry-lab.github.io/intro-baseline-review/ 。公司介绍和经理简介在「第二步 · 内容底稿」里直接改。改乱了可以点对应卡片上的「恢复内置」。

页面上的修改只保存在当前浏览器。要换成一套新的内置底稿，再替换 `assets` 里的 Excel 或两份 Word，推送到 `main` 后网站会更新。已经在网页上改过的浏览器仍会优先使用本机保存的内容。

本机预览时，在这个目录执行 `python3 -m http.server 4173`，再打开 `http://127.0.0.1:4173/`。不要直接双击 `index.html`。
