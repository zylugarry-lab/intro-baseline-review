# 介绍底稿核对

把公司介绍和投资经理 / 基金经理介绍维护成一份底稿，再拿去和一页通比对。对不上的内容直接改成 Word 修订，可以下载。

页面只在浏览器里处理文件，不会把材料上传到服务器。

## 两步

1. **内容底稿**
   - `assets/manager-introductions.xlsx`：姓名、简介、从业日期、投资起始日期。
   - `assets/company-introduction-general.docx`：通用版公司介绍。
   - `assets/company-introduction-ccb.docx`：建行版公司介绍。
   - 从业年限、投资年限用制作日期减去对应起始日期，按 365 天下取整。不满一年保留一位小数。
   - “14年证券期货从业经验，其中10年固定收益投资经验”这类句子里的年限会跟着日期变。简介里的其他表述、两份公司介绍 Word，都是手动更换文件来维护。

2. **对照一页通**
   - 先选择用通用版还是建行版做比对。
   - 上传一页通 docx。公司介绍或经理介绍和底稿不一致时，写入 Word 修订。
   - 没被改到的旧修订保持原样。

## 本地打开

在这个目录执行：

```bash
python3 -m http.server 4173
```

浏览器打开 `http://127.0.0.1:4173/`。不要直接双击 `index.html`，模块脚本需要通过网页地址打开。

## 发布到 GitHub Pages

把这个目录推到 GitHub 仓库，在仓库 Settings → Pages 里选择从主分支的根目录发布。站点地址会是 `https://用户名.github.io/仓库名/`。

更新底稿时，替换 `assets` 里的 Excel 或两份 Word，再重新发布。页面上也支持临时更换，更换结果只保存在当前浏览器。
